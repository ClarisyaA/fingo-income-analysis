# A/B Testing Report — Fingo Weekly Income Forecasting

## Disclaimer
A/B Testing ini adalah **simulasi offline** karena aplikasi Fingo belum live.

## Desain
- Control (A): Tanpa insight prediksi
- Treatment (B): Dengan insight prediksi income dan direction

## Hasil
- Control mean: 59.76
- Treatment mean: 60.99
- Uplift: 2.06%
- p-value: 0.322483
- Signifikan: Tidak (α = 0.05)
- T-statistic: 0.9909

## Interpretasi
Belum signifikan secara statistik — perlu lebih banyak data.

## Catatan
Rancangan ini dapat diterapkan setelah aplikasi Fingo memiliki pengguna aktif >= 200.
